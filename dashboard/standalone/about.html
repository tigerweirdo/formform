FORM/FORM

A personal project. Last updated October 5, 2026.

FORM/FORM generates original abstract, seamlessly looping videos and measures which visual styles people respond to, so the next videos can be better.

How it uses TikTok

  • Drafts, not automatic posts. Each video is uploaded as a draft to the owner's own TikTok inbox. The owner reviews it and publishes it manually in the TikTok app. The tool never posts on its own.
  • Own statistics only. It reads public statistics of the owner's own videos (views, likes, comments, shares) to learn which styles perform best.
  • One account. The tool is operated by an individual and connected to a single TikTok account, the owner's. It is not a public service and has no sign-up for other users. It does not access any other user's data.

How it works

  1. The tool renders a new original video, seamlessly looping, 8 to 30 seconds, vertical, with its own generated ambient sound.
  2. It uploads the video as a draft to the owner's TikTok inbox (video.upload).
  3. The owner opens the draft in TikTok, adds the caption and publishes it manually.
  4. The tool reads the statistics of the owner's own videos (video.list) and learns which visual styles perform best, so the next videos can be better.

Connect TikTok (owner only)

Connecting an account is restricted to the owner, who needs a private setup key. The flow uses TikTok Login Kit: the owner is sent to TikTok's own consent screen, which lists the permissions below, approves them, and returns to this site. Nothing is posted until the owner publishes a draft. Connect TikTok

Requested TikTok permissions

  • video.upload: send a draft to the owner's inbox.
  • user.info.basic and video.list: identify the connected account and read the statistics of its own videos.
