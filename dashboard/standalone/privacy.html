Privacy Policy

FORM/FORM · Last updated October 5, 2026

FORM/FORM is a personal project operated by an individual (the "owner"). It is connected to the owner's own TikTok account and is not offered to the public. This policy explains what data the project handles.

What data is handled

  • When the owner connects their TikTok account: the account's open ID, display name and avatar, and the OAuth access and refresh tokens that TikTok issues.
  • Statistics of the owner's own videos: video ID, title, creation time, and counts of views, likes, comments and shares.

No other TikTok user's personal data is requested, collected or stored. Visitors of this website are not asked for any information.

Why

To upload videos as drafts to the owner's inbox and to measure how the owner's own videos perform, so that future videos can be improved. The data is used for nothing else.

Where it is stored

Tokens are stored encrypted and statistics as plain tables in a private GitHub repository that only the owner can access. The project runs on GitHub Actions. These pages are hosted by Cloudflare, which, like any web host, may process technical request data such as IP addresses. This website sets no cookies and runs no analytics or advertising.

Sharing

The data is not sold, shared with third parties, or used for advertising or profiling. It is shared only with the service providers named above, as needed to run the project.

Retention and your choices

Data is kept while the project is in use. The owner can revoke the connection at any time in the TikTok account settings (apps and permissions), after which the stored tokens stop working and the owner removes them. To ask for deletion of any data, write to contact@example.com; requests are handled within 30 days.

Children

The project is not directed to children and does not knowingly handle data of anyone under 16.

Changes and contact

If this policy changes, the date above changes. Contact: contact@example.com.
